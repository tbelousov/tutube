# 📺 Tutube v1.2 — Сервис непредсказуемых уведомлений

Видеоплатформа с интеллектуальной системой уведомлений, которая анализирует поведение пользователей и отправляет персонализированные сообщения. Разработано как тестовое задание (и по ТЗ) **AlumniHub**.

[![Java](https://img.shields.io/badge/Java-17+-orange.svg)](https://openjdk.org/)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.5.7-brightgreen.svg)](https://spring.io/projects/spring-boot)
[![Docker](https://img.shields.io/badge/Docker-ready-blue.svg)](https://www.docker.com/)

Хранилище данных: полностью in-memory (без БД). Все репозитории реализованы на ConcurrentHashMap.
Данные очищаются при рестарте приложения.

## 📢 Пролог
Первым делом в голову пришла идея пивного приложения. Я в пиве не спец, но сама идея показалась многообещающей: возможность заказывать пиво, бронировать столики, получать рекомендации по локациям в зависимости от погоды или дня недели, а также взаимодействовать с друзьями через посты и комментарии. Например, можно предложить пиво по погодным условиям, напомнить о другом баре, если друг уже зачекинен, или предложить что-то новое по вкусовым предпочтениям. Много метрик => очень много комбинаций.

Сделав шаг дальше, я понял, что количество возможных правил и функционала для такого проекта может быть колоссальным. Поэтому я решил сфокусироваться на более узкой нише, чтобы архитектура оставалась понятной, а код - прозрачным. Так появилась идея для видео-сервиса **Tutube**.

В этом приложении пользователи могут просматривать видео, подписываться на каналы, оставлять комментарии, лайкать видео или комментарии, а также поддерживать каналы через донаты. Локация и погода играют свою роль в предсказаниях и рекомендациях, а уведомления формируются на основе поведения пользователей, чтобы предложить им наиболее релевантные и неожиданные сообщения.

## 🎯 Ключевые особенности

### 1️⃣ Умные триггеры (26 правил)
Система анализирует действия пользователя и отправляет контекстные уведомления:
- 🦉 **Ночная сова** - если пользователь пишет комментарии ночью 3 дня подряд
- ☔ **Погодные рекомендации** - предлагает домашний контент в дождь/снег
- ⏩ **Пропуск интро** - замечает, если пользователь постоянно скипает интро на канале
- 💰 **Донатер-лоялист** - поощряет за просмотр задоначенных каналов
- ⚖️ **Важны все мнения** - замечает, если пользователь старается смотреть видео противоположных лагерей
- 📈 **Топ-комментарий** - предлагает комментировать ещё, если комментарий юзера набрал много лайков
- 🐫 **Ленивый шейх** - удивляется, если пользователь не лайкает видео каналов, которым донатит
- 🔥 **Топ-тема** - любимая тема видео пользователя тоже нуждается в уведомлении
- ✏️ **Граммар-наци** - предлагает видео про грамматику, если пользователь регулярно пишет комментарии с ошибками
- 💬 **Любитель текста** - пользователь лайкает комментарии, но не лайкает само видео (подозрительно)
- 🧭 **Новое место** - предлагает видео о новом месте, если пользователь сменил локацию
- 🌀 **Эффект Манделы** - если пользователь смотрит короткие куски разных видео на одну тему, перематывает, комментирует - явно ищет что-то конкретное
- 🌦️ **Метеочувствительность** - пользователь в разные дни при смене погоды включает Relax: он чувствует погоду
- 🎰 **Геймификация** - если пользователь посмотрел (9, 49, 99...) видео на одну тему, надо обязательно довести до круглого числа
- 💢 **Спираль негатива** - предлагает остудиться, если пользователь смотрит холиварные темы и пишет гневные комментарии
- 🌙 **Ночной альтруист** - пользователь донатит строго по ночам - может пьяный? =)
- 💸 **Донат с ЗП** - донатил в один и тот же день месяца 3 раза подряд, но в этот раз - нет. ЗП задерживают?
- ✈️ **Рабочие поездки** - предлагает предзагрузить видео в полёт, если пользователь регулярно резко меняет локацию
- 🔁 **Фоновое** - замечает, если пользователь смотрит одно и то же видео несколько раз в день
- 🕰️ **Тени прошлого** - подбадривает, если пользователь обучался чему-то, потом забросил, но потом стал смотреть видео на схожую тематику
- 🗣️ **Дискуссия** - предлагает подискутировать с самым популярным комментарием под видео из подписок
- 👀 **Канал друга** - удивляется, если пользователь подписан, но долгое время не смотрит ни одного видео канала
- ⏳ **Время-деньги** - предлагает видео покороче, если пользователь вот уже 3 дня не может досмотреть ни одно видео на тему
- 🌇 **Вечернее видео** - замечает, что вечер - самое время досмотреть брошенное видео
- 💞 **Тайный поклонник** - удивляется, если пользователь досматривает видео канала, но не лайкает и не комментирует
- 🗓️ **Было время** - замечает, если год назад в этот же день пользователь смотрел видео на эту же тему

### 2️⃣ AI-режим (GPT-4o-mini)
Посвящается условию из ТЗ "нельзя сделать просто с помощью ChatGPT". Challenge accepted.  
Система может генерировать уведомления через OpenAI API:
- Анализирует паттерны поведения за последний месяц
- Учитывает контекст (погода, локация, устройство)

### 3️⃣ Гибридный режим
Пользователь выбирает:
- `RULES_ONLY` - только эвристические правила
- `AI_ONLY` - только AI-генерация
- `HYBRID` - комбинация (по умолчанию)

### 4️⃣ Тон уведомлений
- добрый, дружелюбный
- пассивно-агрессивный 😏 (вдохновлялся Duolingo)

### 5️⃣ Интеллектуальный Throttling
- Максимум 5 уведомлений в час, 20 в день
- Минимальный интервал между доставками (10 минут)
- Дедупликация по типу триггера (24 часа)
- Ограничение очереди на пользователя (50 pending)

### 6️⃣ Без Cron
Уведомления планируются индивидуально через `ScheduledExecutorService` сразу после создания - никаких периодических проверок!

## 🚀 Быстрый старт

### Предварительные требования
- Java 17+
- (Опционально) Docker
- (Опционально) OpenAI API key для AI-режима

### 1. Клонирование
```bash
git clone https://github.com/tbelousov/tutube
cd tutube
```

### 2. Настройка окружения
Создайте `.env` файл:
```bash
# Опционально для AI
AI_ENABLED=true
AI_API_KEY=sk-proj-YOUR_KEY_HERE
AI_MODEL=gpt-4o-mini
AI_TRIGGER_PROBABILITY=0.2

# Логи
LOG_LEVEL=INFO
```

### 3. Запуск (Docker)
```bash
docker-compose up -d
```

Приложение будет доступно на `http://localhost:8080`

### 4. Локальный запуск (без Docker)
```bash
./gradlew bootRun
```

## 🔌 API Примеры

### Создать пользователя
```bash
curl -X POST http://localhost:8080/users \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Alice",
    "timezone": "Europe/Moscow",
    "toneProfile": "PASSIVE_AGGRESSIVE",
    "mode": "HYBRID"
  }'
```

### Отправить действие (ночной комментарий)
```bash
curl -X POST http://localhost:8080/actions \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 1,
    "actionType": "COMMENT",
    "timestamp": "2025-10-31T02:30:00Z",
    "deviceType": "MOBILE",
    "videoId": 42,
    "channelId": 7,
    "commentId": 123,
    "weather": "rainy",
    "location": "Moscow"
  }'
```

### Получить уведомления пользователя
```bash
curl http://localhost:8080/notifications/user/1
```

### Получить все уведомления
```bash
curl http://localhost:8080/notifications
```

## 📊 Мониторинг

Метрики доступны через **Spring Boot Actuator**:

- Health: `http://localhost:8080/actuator/health`
- Metrics: `http://localhost:8080/actuator/metrics`
- Prometheus: `http://localhost:8080/actuator/prometheus`

### Ключевые метрики
- `tutube.notifications.created{source,trigger}` - созданные уведомления
- `tutube.notifications.throttled{reason}` - заблокированные throttling'ом
- `tutube.rules.evaluations{rule,triggered}` - срабатывания правил
- `tutube.ai.call.duration{success}` - время вызова AI

## 🛠️ Конфигурация

### application.yml
```yaml
tutube:
  ai:
    enabled: true
    trigger-probability: 0.2  # 20% шанс вызова AI
  
  throttle:
    min-interval: 10m         # мин. интервал между уведомлениями
    max-per-hour: 5
    max-per-day: 20
    max-pending-per-user: 50
    deduplicate-window: 24h   # не дублировать триггер 24 часа
  
  notifications:
    cooldown-hours: 24        # правило не сработает повторно 24 часа
```
